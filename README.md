# 엔트릭 데이터 API

국내 공개 데이터를 정제해 개발자에게 API로 공급합니다. 이 저장소는 **고객이 읽는 문서의 창구**입니다. 명세, 서비스 수준, 체험 안내, 기계 판독용 OpenAPI가 여기 있습니다.

기본 주소는 `https://api.ntriq.co.kr` 입니다. 문의는 ceo@ntriq.co.kr.

## 법원경매

전국 법원의 경매 물건, 기일 회차, 물건 상세, 권리분석을 JSON으로 제공합니다.

| 문서 | 내용 |
|---|---|
| [명세서](docs/auction/spec.md) | 엔드포인트, 필드, 식별자 규약, 갱신 주기, 원천 데이터의 제약 |
| [서비스 수준](docs/auction/sla.md) | 가동률, 갱신 약속, 데이터 신선도, 이용 조건 |
| [체험 안내](docs/auction/trial.md) | 체험 키로 처음 연결하기 |
| [MCP 빠른 시작](docs/auction/mcp.md) | AI 에이전트에서 바로 쓰기 |
| [OpenAPI](openapi/auction.json) | 기계 판독용 정본. 문서와 어긋나면 이쪽이 맞습니다 |

연결 확인은 한 줄이면 됩니다.

```bash
curl -H "X-YAP-Key: $NTRIQ_KEY" \
  "https://api.ntriq.co.kr/lawink/api/v1/auction/health"
```

## 이용 범위

**기본 계약은 내부 이용입니다.** 재배포, 재판매, 제3자 제공, 고객 화면 노출이 모두 포함되지 않습니다. 받으신 데이터를 사내 분석과 내부 시스템에서 쓰시는 범위입니다.

화면에 보여주시거나 재가공해 파시려면 **별도 계약이 필요합니다.** 범위에 따라 조건이 다르니 ceo@ntriq.co.kr 로 문의하십시오.

화면 노출이 허용된 계약에서는 **출처를 표시하셔야 합니다.** 저작권법 제37조(출처 명시 의무)이자, 원천인 대한민국 법원 법원경매정보가 재사용을 허락하는 조건입니다. 응답의 `source.notice` 문구를 사람이 읽을 수 있는 자리에 그대로 노출하십시오. 같은 값이 응답 헤더 `X-Data-Source` 로도 나갑니다. 자세한 내용은 [명세서 7절](docs/auction/spec.md)에 있습니다.

## 어떻게 모으나

원천은 대한민국 법원 법원경매정보(courtauction.go.kr)의 **공개 정보뿐**입니다.

**로그인, 캡차, 인증 우회를 하지 않습니다.** 로그인 뒤에만 보이는 정보는 수집하지 않고 제공하지도 않습니다. 원천 사이트에 부담을 주지 않도록 요청 간격과 하루 분량에 스스로 상한을 둡니다.

개인 이름은 가려서 드립니다. 법인명은 가리지 않습니다.

## 바뀌는 것

필드와 갱신 주기는 약속이며 바뀔 때는 미리 알립니다. 무엇이 언제 바뀌었는지는 [CHANGELOG](CHANGELOG.md)에 적습니다.

## 이 저장소에 대하여

여기 있는 문서는 전부 사내 정본에서 복사됩니다. 직접 고치지 마십시오. 다음 복사에 덮어써집니다. 잘못된 내용을 발견하시면 이슈나 메일로 알려 주십시오. 정본을 고쳐서 반영합니다.

코드는 없습니다. 문서와 OpenAPI 스키마만 있습니다.
