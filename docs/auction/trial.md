# 법원경매 데이터 API 체험 안내

## 체험 조건

**한 법원, 7일입니다.** 평가에 필요한 만큼을 드리는 자리이고 전국을 여는 자리가 아닙니다. 보실 법원은 문의하실 때 정합니다.

| 항목 | 값 |
|---|---|
| 기간 | 첫 호출부터 7일 |
| 범위 | 협의한 법원 한 곳 |
| 한도 | 하루 200회, 월 1,000회 |
| 한 번에 받는 건수 | 20건 |
| 발급 뒤 미사용 | 30일이 지나면 키가 닫힙니다 |

**상세와 회차의 채움은 법원마다 다릅니다.** 법원을 정하실 때 그 법원의 현재 채움 상태를 함께 알려 드립니다. 상세가 아직 없는 물건은 `detail`이 `null`로 나갑니다.

**기간은 첫 호출에 시작합니다.** 받아 두고 준비가 된 뒤에 쓰셔도 손해가 없습니다.

키는 한 번만 표시되니 받는 즉시 안전한 곳에 보관하세요. 문의는 ceo@ntriq.co.kr 로 주십시오.

## 연결 확인

```bash
curl -H "X-YAP-Key: <발급키>" \
  "https://api.ntriq.co.kr/lawink/api/v1/auction/health"
```

## 남은 횟수

모든 응답의 `X-RateLimit-Remaining` 헤더에 실려 나갑니다. 하루 한도는 `X-Trial-Daily-Remaining` 으로 따로 나갑니다. 본문을 읽지 않아도 확인됩니다.

## 체험에서 막히는 것

한 번에 21건 이상을 요청하시면 오류가 납니다. 전량 내려받기는 계약 뒤에 스냅샷으로 드립니다.

협의한 법원 밖을 조회하시면 범위 밖이라는 응답이 옵니다. 법원을 늘리시려면 문의해 주십시오.

## 그다음

전체 엔드포인트와 필드 규격은 [명세서](spec.md)에, 서비스 수준과 이용 조건은 [SLA](sla.md)에 있습니다. AI 에이전트에 바로 붙이시려면 [MCP 안내](mcp.md)를 보십시오.

## 막혔을 때

오류를 알리실 때 응답 헤더의 `X-Request-ID` 값을 함께 적어 주시면 서버 로그에서 그 요청을 바로 찾습니다.
